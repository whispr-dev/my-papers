# Contributing Guide

Thanks for your interest in improving this thesis/code repository!

## Code Style

- Follow Python3.14 2025 edition conventions (for Python code)
- Keep logic minimal; avoid unnecessary dependencies

## Workflow

1. Fork the repository
2. Create a feature branch:
   git checkout -b feature/your-feature
3. Commit with clear, conventional messages:
   feat: add feature
   fix: resolve bug
4. Open a Pull Request against main

## Testing

- `Python xxxxxx.py`
- Manual: Create temporary files; compare before/after with hex viewers

## Documentation

Update README.md if you add a feature.

## Communication

Open an Issue for:
- Feature requests
- Bug reports
- Questions/clarifications

Thanks for keeping this repo clean, efficient, and reliable!
