\# Thesis Backup \& Lightning Protection Repository

This repository is a backup copy of Ludmilla’s undergrad thesis on lightning protection systems (SPDA), NBR 5419:2015, and all related computational code, measurement protocols, and appendices.

The project demonstrates a near-PhD/PostDoc level thesis assembled in under 1 hour, with 300+ pages of technical material, computational analysis, and standards compliance. Most of the time is spent ensuring correct formatting and standards adherence.



\*\*Current Contents:\*\*

\- Main thesis markdown

\- Appendices A–I

\- Computational source code (risk assessment, grounding analysis, SPD design)

\- Figures, diagrams, and case studies

\- Changelog, code of conduct, license, security policy, and contributing guide



This backup is maintained so the work never gets lost (strong protection against user error or data accidents)!
