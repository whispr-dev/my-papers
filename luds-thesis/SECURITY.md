# Security Policy

## Supported Versions

| Version  | Supported  |
|----------|------------|
| 0.4.x    | ✅ Active  |

## Reporting a Vulnerability

Do not open a public GitHub issue for vulnerabilities.
Contact the maintainer:
- Email: security@whispr.dev
- Or use GitHub's “Report a vulnerability” feature.

Response expected within 72 hours.

## Scope

Focus: software-level protection for SPDA computation and thesis code.  
Does not cover physical hardware erasure or sanitization for peripherals/cloud.

## Verification

Users are encouraged to review and audit the source before deployment.
